# ✋ Hand Gesture Recognition

A computer vision project built using Python, OpenCV, and MediaPipe to detect and track hand movements in real time using a webcam.

## 🚀 Features

- Real-time hand detection using a webcam
- Hand landmark tracking
- Computer vision using OpenCV
- Hand tracking powered by MediaPipe

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe

## 📋 Requirements

- Python installed on your computer
- A working webcam
- Required Python libraries

## ⚙️ Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/syedarbaz2021-sudo/hand-gesture-recognition.git
   ```

2. Open the project folder:

   ```bash
   cd hand-gesture-recognition
   ```

3. Install the required libraries:

   ```bash
   pip install opencv-python mediapipe
   ```

4. Run the program:

   ```bash
   python hand.py
   ```
